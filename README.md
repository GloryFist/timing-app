# Тайминг — учёт времени с выгрузкой в Excel

Мобильное приложение (PWA) для фиксации времязатрат и макрос, который добавляет выгрузку в книгу `Тайминг.xlsm` на лист года в таблицу `tblData`.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html`, `styles.css`, `app.js`, `core.js` | Приложение: таймер, ручной ввод, журнал, выгрузка |
| `manifest.webmanifest`, `sw.js`, `icons/` | Установка на главный экран и офлайн-работа |
| `dist/` | Сборка для хостинга; в архив попадают только файлы приложения |
| `ImportTiming.bas` | Макрос импорта CSV в книгу, кодировка Windows-1251 |
| `tests/` | Тесты логики, сценарии браузерной проверки, UTF-8 исходник макроса |

Архив для загрузки на хостинг: `timing-app.zip` рядом с папкой приложения — чистый набор файлов без служебных папок проверки.

## Быстрый старт на компьютере

1. Откройте `dist/index.html` в Chrome.
2. Введите деятельность и нажмите «Старт». Кнопка «Переключить» закрывает текущий интервал и начинает новый, «Стоп» — закрывает.
3. «+ Добавить» — ручной интервал задним числом.
4. «Выгрузка» → «Скачать CSV». Файл попадёт в «Загрузки».

Локальное открытие по `file://` работает для ввода и выгрузки, но не даёт установку на телефон и офлайн-кэш: для этого нужен HTTPS.

## Установка на Android

PWA устанавливается только по HTTPS. Подойдёт любой статический хостинг:

- **GitHub Pages**: создайте репозиторий, загрузите содержимое `dist/`, включите Pages (ветка `main`, корень). Откройте выданный адрес в Chrome на телефоне.
- **Cloudflare Pages / Netlify**: загрузите папку `dist/` как статический сайт.
- **Свой сайт**: положите файлы из `dist/` в любую папку с HTTPS.

На телефоне: откройте адрес в Chrome → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»). После первого открытия приложение кэшируется и работает без интернета.

Проверка по локальной сети (`http://192.168.x.x:8000`) годится только для просмотра: установка и service worker на HTTP не работают.

## Импорт CSV в книгу

1. Откройте `Тайминг.xlsm` в Excel, разрешите макросы.
2. `Alt+F11` → File → Import File… → выберите `ImportTiming.bas`. Модуль появится с именем `ImportTiming`.
3. Вернитесь в Excel: `Alt+F8` → `ИмпортИзCSV` → «Выполнить».
4. Выберите CSV, скачанный из приложения (например, из папки Dropbox).
5. Проверьте добавленные строки и сохраните книгу — макрос сам книгу не сохраняет.

Что делает импорт:

- вставляет строки в `tblData` листа с годом из даты (сейчас `2026`) в хронологическом порядке;
- заполняет дату, начало, окончание, деятельность и примечание (столбцы B, C, E, J, O);
- подтягивает формулы таблицы (A, D, F, G, H, Z, AA);
- пересчитывает цепочку `Z`/`AA` для затронутых дней, чтобы «Итого, ч/р.д.» не теряло вставленные интервалы;
- пропускает дубли по совпадению «дата + начало + деятельность»;
- запускает `AutoFillingCat`, который заполняет группы и классификацию (P–Y);
- выводит отчёт: добавлено, дублей, ошибок, статус классификации.

Если строки относятся к году, для которого нет листа (например, 2027), они пропускаются с сообщением в отчёте.

## Формат CSV

```
Дата;Начало;Конец;Деятельность;Примечание
09.11.2026;09:15;09:40;Проверка @;
```

- кодировка UTF-8 с BOM, разделитель `;`, перевод строки CRLF;
- дата `ДД.ММ.ГГГГ`, время `ЧЧ:ММ`;
- поля с `;`, кавычками или переводом строки экранируются кавычками;
- незакрытые интервалы в выгрузку не попадают, пока не нажато «Стоп».

## Данные и резервные копии

Записи хранятся только в браузере телефона (`localStorage`), на сервер ничего не отправляется. Очистка данных сайта в Chrome удалит записи.

На экране «Выгрузка» → «Резервная копия и восстановление» можно скачать JSON-копию и восстановить её на другом устройстве. Это единственный способ переноса между телефонами.

## Ограничения

- Интервалы через полночь не поддерживаются: незакрытый интервал автоматически закрывается в 23:59.
- Выгрузка идёт только по закрытым интервалам; текущий интервал нужно остановить.
- Повторный импорт того же файла безопасен, но если изменить текст деятельности в Excel, строка при повторном импорте будет воспринята как новая.
- Классификация выполняется макросом книги; если модуль `AutoFillingCat` переименован, импорт сообщит «не выполнена» — запустите классификацию вручную.
